Fantasy RPG Prototype

Desarrollo de un prototipo de juego RPG de fantasía en 3D. Este proyecto se centró en la implementación de mecánicas de combate por turnos, sistema de inventario, navegación de personajes y un entorno interactivo.

Tecnologías Clave: Desarrollo en **Unity 3D** utilizando scripts en **C#** para toda la lógica del juego. Se utilizó **Blender** para el modelado 3D de personajes y entornos, y **Photoshop** para las texturas.

Características: Combate por turnos, sistema de habilidades y equipamiento, inteligencia artificial básica para enemigos, sistema de guardado/carga de partida.

Tecnologías Utilizadas:
Unity 3D C# Blender Photoshop
